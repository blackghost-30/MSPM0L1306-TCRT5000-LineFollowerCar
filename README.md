# MSPM0L1306-TCRT5000-LineFollowerCar

基于 TI MSPM0L1306 (ARM Cortex-M0+) 开发的两轮有刷电机循迹小车驱动工程。本项目实现了从底层外设驱动到上层控制算法的完整链路，支持 PWM 调速、差速转向、红外循迹与 PID 闭环控制。

------

## 项目简介

本工程为2025年全国大学生电子设计竞赛 E 题的循迹驱动部分，利用 TI 最新的 MSPM0 系列芯片，配合 **SysConfig** 图形化配置工具，实现了高效、模块化的代码结构。

**核心特性：**

- **图形化配置**：基于 `empty.syscfg`，外设初始化一目了然。
- **闭环控制**：集成增量式 PID 算法，确保循迹平滑稳定。
- **模块化封装**：硬件驱动（Hardware 层）与逻辑代码完全解耦，方便移植。

------

## 硬件架构

| **模块**       | **型号/方案**    | **备注**                 |
| -------------- | ---------------- | ------------------------ |
| **主控芯片**   | TI MSPM0L1306    | ARM Cortex-M0+ @ 32MHz   |
| **电机驱动**   | TB6612FNG        | 双路 H 桥，支持 PWM 调速 |
| **循迹传感器** | 5 路 TCRT5000    | 红外反射式，数字量输出   |
| **动力源**     | 双路直流有刷电机 | 普通的有刷电机           |

## 目录结构

```
Hardware/
├── Delay.c/h        # 毫秒级系统延时
├── PWM.c/h          # Timer_A 生成多路 PWM，控制电机转速
├── TB6612.c/h       # 逻辑电平控制电机方向（正/反/刹车）
├── TCRT5000.c/h     # 传感器数据采集与状态逻辑
└── Trace.c/h		 # 核心算法：加权误差计算与 PID 控制器
empty.syscfg         # TI 图形化配置工具文件（关键）
empty.c              # Main 循环与任务调度
```

------

## 功能清单

1. **动力系统**：双路 PWM 输出，支持 0~100% 细粒度占空比调节。
2. **运动控制**：支持前进、后退、原地转向、差速转向。
3. **智能循迹**：
   - 采用**加权误差算法**：根据 5 路传感器的触发位置计算偏移量。
   - **增量式 PID**：实时修正转向误差，消除轨迹震荡。
   - **特殊地形处理**：内置自动 90° 直角转弯逻辑。
4. **系统保护**：软件限幅与速度斜坡控制，防止电机瞬间过载。

## 快速上手

### 1. 环境准备

- 安装 [Code Composer Studio (CCS)](https://www.ti.com.cn/tool/cn/CCSTUDIO)。
- 安装对应版本的 [MSPM0 SDK](https://www.ti.com.cn/tool/cn/MSPM0-SDK)。

### 2. 导入与编译

1. 打开 CCS，选择 `File -> Import -> Eclipse projects`。
2. 选择本工程根目录导入。
3. 点击 **Hammer** 图标编译（确保 Zero Errors）。

### 3. 接线参考

> **注意**：请务必将电机驱动电源（VM）与逻辑电源（VCC）分开，并共地（GND）。

- **PWM 引脚**：请参考 `empty.syscfg` 中的引脚映射。
- **传感器引脚**：接入对应的 GPIO 输入口。

------

## 核心算法说明

### 循迹误差计算

通过对 5 路传感器分配权值（-2, -1, 0, 1, 2），计算中心偏移量。

### PID 调节

工程采用增量式 PID 公式：

$$\Delta u = K_p e(k) + K_i e(k-1) + K_d e(k-2)$$

## 注意事项

- **路径问题**：工程所在路径严禁包含**中文或空格**，否则编译会报错。
- **参数整定**：不同机械结构的重心和摩擦力不同，请根据实际情况调整 `Trace.c` 中的 `KP, KI, KD` 参数以及函数内部的延时。
- **电源管理**：建议使用 7.4V 锂电池经稳压后给开发板供电，TB6612 的 VM 端直接接电池正极。
